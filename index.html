LabelCheck AI v25

Alcohol label verification assistant for routine compliance checks.

Simple workflow: Single Review keeps one application uncluttered. Batch Processing is separated into its own tab.

Local-first mode

1. Applicant statement import

Start here. Upload the applicant's TTB F 5100.31 PDF, email, TXT, CSV, or JSON. The app reads the submitted PDF package as visible/textual evidence when possible, then fills reviewer-editable fields below.

Agent tip: Upload the application first, then upload or paste the label evidence. The green/yellow/red checks at the bottom are the simple agent view.

2. Application fields found

These are reviewer-editable. The app reads the uploaded application visually/textually when possible and fills the fields it can find. Blank fields mean the application did not provide that value or the app could not read it.

Simple fields: Alcohol content, warning presence, and warning accuracy are shown as Y/N checks after verification so agents do not need to interpret long text fields.

3. Label evidence

Upload the label image or paste label text. The app scans the full label image/package for the Government Warning. If OCR is noisy, the agent can still paste readable label text.

Package check: When a warning is visible on the uploaded image, the app should mark Warning Present = Y. If OCR cannot read it, paste the warning text into the box below and verify again.

Batch application PDF extraction

Upload multiple electronically filled TTB F 5100.31 PDFs to extract application metadata into a batch CSV. ABV, net contents, and warning columns stay blank unless supplied by a separate applicant export/specification.

Batch verification

Paste CSV rows with headers: brand,productName,alcoholType,abv,netContents,labelText. This supports importer-style bulk review without COLA integration.

Prototype only. Supports human-in-the-loop review and does not make legal approval decisions. Review flags mean “check the submitted label package,” not automatic rejection.
